# Лабораторная работа №4. Основы JavaScript

## Цель

Познакомиться с синтаксисом JavaScript, базовыми конструкциями и логикой.

## Описание

В рамках лабораторной работы к HTML-странице «Студент-разработчик» добавлен JavaScript-файл `script.js`, который обрабатывает баллы за лабораторные работы.

Скрипт выполняет следующие действия:

* запрашивает имя студента с помощью `prompt()`;
* выводит приветствие и результаты через `alert()`;
* хранит баллы за шесть лабораторных работ в массиве;
* находит максимальный балл с помощью функции `findMax()`;
* отбирает отличные результаты (баллы не ниже 80) с помощью функции `filterHighScores()`;
* вычисляет сумму баллов с помощью функции `calculateSum()`;
* с помощью цикла подсчитывает количество неудовлетворительных работ (баллы ниже 50);
* выводит средний балл и количество неудовлетворительных работ в консоль браузера;
* при среднем балле не ниже 85 выводит дополнительное мотивационное сообщение.

## Вариант работы

**Вариант 1.** Тема «Студент-разработчик» (баллы за лабораторные работы). Используется массив из 5–7 чисел в диапазоне от 0 до 100. Функция фильтрации оставляет баллы ≥ 80. Цикл подсчитывает количество работ с баллом < 50. Функции `findMax()`, `filterHighScores()` и `calculateSum()` находят максимальный балл, фильтруют отличные результаты и вычисляют сумму баллов соответственно.

Результаты выводятся через `alert()` и `console.log()`. Дополнительно, если средний балл ≥ 85, в консоль выводится мотивационное сообщение.

## Использованные технологии

* HTML5
* CSS3
* JavaScript
* Массивы, функции, условные конструкции и циклы
* `prompt()`, `alert()` и `console.log()`

## Запуск проекта

Открыть файл `index.html` в любом современном браузере. При загрузке страницы скрипт запросит имя студента. Результаты выполнения можно посмотреть в диалоговом окне и в консоли браузера (клавиша `F12`, вкладка Console).

Для корректного отображения фотографии студента и галереи необходимо разместить соответствующие изображения в папке `images` и проверить правильность путей к файлам.
