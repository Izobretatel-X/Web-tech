# Лабораторная работа №5. DOM и взаимодействие с элементами страницы

## Цель

Научиться манипулировать DOM-деревом, находить элементы, изменять содержимое и стили, а также сохранять состояние страницы между перезагрузками через `localStorage`.

## Описание

В рамках лабораторной работы к HTML-странице «Студент-разработчик» добавлено управление списком карточек проектов. Вся логика находится в файле `script.js` (после кода лабораторной работы №4), новые стили — в `style.css`, новые кнопки — в `index.html`.

Реализованные функции:

* кнопка «Добавить проект» запрашивает название и описание через `prompt()` и создаёт новую карточку (`<article>` с заголовком `<h3>`, описанием `<p>` и кнопкой «Подробнее») с помощью `document.createElement()`; карточка добавляется в контейнер через `appendChild()`;
* кнопка «Удалить последний» находит все карточки через `querySelectorAll()` и удаляет последнюю методом `remove()`; если карточек нет, в консоль выводится «Нет проектов для удаления» и показывается `alert` «Список пуст»;
* кнопка «Тёмная тема» / «Светлая тема» переключает класс `theme-light` / `theme-dark` у `<body>`, а CSS-переменные обновляются автоматически;
* кнопка «Свернуть проекты» / «Развернуть проекты» добавляет или убирает класс `hidden` у контейнера списка проектов;
* кнопка «Подробнее» у добавленных карточек показывает название и описание проекта в диалоговом окне;
* перед любыми действиями проверяется существование контейнера и всех кнопок; если элемент не найден, в консоль выводится ошибка «Элемент не найден: [селектор]», а скрипт лабораторной работы №5 не запускается;
* выбранная тема и список карточек проектов сохраняются в `localStorage` и восстанавливаются при загрузке страницы.

## Вариант работы

**Вариант 1.** Тема «Студент-разработчик» (управление проектами). Контент — список карточек проектов (заголовок, краткое описание, кнопка «Подробнее»).

## Использованные технологии

* HTML5
* CSS3 (CSS-переменные, классы тем)
* JavaScript
* DOM API: `getElementById()`, `querySelector()`, `querySelectorAll()`, `createElement()`, `appendChild()`, `remove()`, `classList`
* `localStorage`
* `prompt()`, `alert()` и `console.log()`

## Запуск проекта

Открыть файл `index.html` в любом современном браузере. При загрузке страницы сначала сработает скрипт лабораторной работы №4 (запрос имени и приветствие), после чего станут доступны кнопки управления проектами. Результаты работы можно посмотреть на странице и в консоли браузера (клавиша `F12`, вкладка Console).

Для корректного отображения фотографии студента и галереи необходимо разместить соответствующие изображения в папке `images` и проверить правильность путей к файлам.
