# Лабораторная работа №6. Введение в Node.js и базовый сервер на Express

## Цель

Освоить запуск Node.js-приложений, работу с модулями, создание простого HTTP-сервера на Express, а также превращение статического сайта в PWA (устанавливаемое приложение с офлайн-режимом).

## Описание

Страница «Студент-разработчик» из лабораторной работы №5 перенесена в папку `public` и теперь раздаётся сервером на Express. Код лабораторных работ №4 и №5 (`script.js`) не менялся. Сервер находится в файле `server.js`, а файлы PWA (`manifest.json`, `pwa.js`, `service-worker.js`) — в папке `public`.

Реализованные функции:

* проект инициализирован командой `npm init`, установлен `express`, добавлен скрипт запуска `npm start`;
* сервер раздаёт статические файлы из папки `public` через `express.static()`;
* маршруты `GET /` (главная страница) и `GET /about` (страница «О себе»);
* маршрут `GET /api/greet/:name` возвращает JSON `{ message, timestamp, lang }`; параметр запроса `?lang=ru` включает русский язык, по умолчанию используется английский;
* имя `:name` проверяется: оно не должно быть пустым или содержать спецсимволы (допустимы буквы любых алфавитов, цифры и дефис, до 50 символов); при неверном имени возвращается `400` и `{ "error": "Invalid name" }`;
* если маршрут не найден, возвращается `404` и `{ "error": "Not found" }`;
* каждый запрос логируется в консоль (время, метод, адрес и код ответа);
* при запуске сервер выводит в консоль «Server started on port 3000»;
* `manifest.json` с названием, цветами и иконками подключён в `index.html` и `about.html`;
* service worker (`service-worker.js`) кеширует статику при установке и отдаёт её из кеша, поэтому сайт работает без сети; регистрация выполняется в `pwa.js`.

## Использованные технологии

* Node.js и npm
* Express (`express.static()`, маршруты, параметры пути `req.params`, query-параметры `req.query`, middleware)
* JSON API, коды ответов 200, 400, 404 и 500
* Web App Manifest
* Service Worker и Cache API
* HTML5, CSS3, JavaScript (код лабораторных работ №4 и №5)

## Запуск проекта

1. Установить [Node.js](https://nodejs.org/) (версия 18 или новее).
2. В папке проекта установить зависимости:

```bash
npm install
```

3. Запустить сервер:

```bash
npm start
```

4. Открыть в браузере `http://localhost:3000`. Порт можно сменить переменной окружения, например `PORT=4000 npm start` (в PowerShell: `$env:PORT=4000; npm start`).

Для корректного отображения фотографии студента и галереи изображения должны лежать в папке `public/images`.
