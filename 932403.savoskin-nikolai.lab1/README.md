# Лабораторная работа №1 — Основы HTML и структура веб-страницы

## Тема

Персональная HTML-страница студента.

## Описание

В рамках лабораторной работы создана персональная веб-страница
с использованием базовых возможностей HTML5 и CSS.

На странице представлены:

- шапка сайта с именем студента;
- изображение;
- список навыков;
- список проектов;
- боковая информационная панель;
- форма обратной связи;
- подвал страницы.

## Вариант работы

**Вариант 1.** Тема «Студент-разработчик»: в секции «Навыки» перечислите 3–4
языка/технологии; в «Проектах» – учебные проекты. В <aside> укажите 2–3 любимых
инструмента (VS Code, Git и т. п.). Цветовая гамма: сине-белая

## Использованные технологии

- HTML5
- CSS3

## Запуск проекта

Открыть файл `index.html` в любом современном браузере.
