# Лабораторная работа №3. Вёрстка макета с помощью Flexbox и Grid

## Цель

Освоить Flexbox для одномерных макетов и CSS Grid для двумерных, а также принципы адаптивной вёрстки.


## Описание

В рамках лабораторной работы была доработана HTML-страница из предыдущих лабораторных работ с использованием Flexbox, CSS Grid и медиазапросов.

На странице представлены:

* шапка сайта с именем и фотографией студента;
* адаптивное навигационное меню, созданное с помощью Flexbox;
* сетка карточек навыков;
* карточки проектов с иконками, описанием, используемыми технологиями и кнопками «Подробнее»;
* галерея скриншотов проектов, оформленная с помощью CSS Grid;
* боковая информационная панель с любимыми инструментами;
* форма обратной связи;
* подвал страницы со ссылкой для возврата в начало.

Реализована адаптивная вёрстка для компьютеров, планшетов и мобильных устройств. При изменении ширины экрана меняется количество колонок в карточках проектов и галерее. Для оформления элементов используются Flexbox, CSS Grid, медиазапросы и эффекты взаимодействия.

## Вариант работы

**Вариант 1.** Тема «Студент-разработчик»: Навигационное меню адаптируется к размеру экрана с помощью Flexbox. Карточки проектов содержат иконки, текстовую информацию, список используемых технологий и кнопки «Подробнее». Для отображения скриншотов проектов используется галерея на основе CSS Grid с подписями к изображениям. Реализована адаптивность для разных размеров экранов, а также контрастное оформление текста и карточек.

## Использованные технологии

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Медиазапросы (@media)

## Запуск проекта

Открыть файл `index.html` в любом современном браузере.
Для корректного отображения фотографии студента и галереи необходимо разместить соответствующие изображения в папке images и проверить правильность путей к файлам.
