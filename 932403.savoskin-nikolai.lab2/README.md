# Лабораторная работа №2 — Базовые и продвинутые возможности CSS

## Тема

Оформление персональной HTML-страницы студента с использованием CSS.

## Описание

В рамках лабораторной работы была визуально улучшена HTML-страница из лабораторной работы №1
с использованием базовых и продвинутых возможностей CSS3.

На странице представлены:

* шапка сайта с именем студента;
* изображение;
* сетка карточек навыков;
* список проектов;
* боковая информационная панель;
* форма обратной связи;
* подвал страницы.

## Вариант работы

**Вариант 1.** Тема «Студент-разработчик»: навыки оформлены в виде сетки карточек-плиток с эффектом масштабирования при наведении и нажатии. В одной из карточек размещён декоративный бейдж «Top skill». Реализованы состояния `:hover`, `:active`, `:focus`, `:visited`, а также позиционирование `static`, `relative` и `absolute`. Цветовая гамма: сине-белая.

## Использованные технологии

* HTML5
* CSS3

## Запуск проекта

Открыть файл `index.html` в любом современном браузере.
